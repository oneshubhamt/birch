# Rustnote 2b.36 implementation

`note_selection_generation` now owns only selection freshness/privacy invalidation. `note_view_generation` owns deliberate same-note component remounts. Vault republishing occurs under the caller's existing publication lease and no longer changes a generation captured by that token. Protect/Lock still remove decrypted selected-note state before storage transition; `VaultTransitionUiState` preserves only non-secret logical selection. Unlock uses the transition pane while authenticating. Synchronization waits briefly for an editable note's editor session to stabilize instead of treating a mount gap as an empty editor. Locked note-list summaries now retain only the persisted user-approved public label from `notes.title`; private preview text, tags, and attachment names are still cleared, and the encrypted real title remains hydrated only while the note session is unlocked.
